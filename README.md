# money-lunch 午饭小助手

同事们一起吃午饭用的小工具：

1. **今天吃什么**：自己填饭店名字，转盘随机抽一家。
2. **饭钱记账**：饭钱统一存在一位同事那里，每天吃了多少就从余额里扣，随时看还剩多少。

金额单位为 **加元（CAD）**。

## 功能

### 今天吃什么（抽奖转盘）
- 手动输入饭店名字，一次可以加多个（逗号、顿号或换行分隔），重复的会自动去掉。
- 至少 2 家饭店才能抽奖，转盘停在哪家就吃哪家。
- 抽完可以一键跳到记账页，饭店名自动填进备注。
- 共享版会保存「今日已抽中」的结果和抽的人，大家都能看到。

### 饭钱记账
- **存入**：有人把钱交给管钱的同事时记一笔，余额增加。
- **消费**：每天吃饭花了多少记一笔，余额自动扣除。
- 显示总余额，按日均消费估算还够吃几天；余额为负时提示该补钱。
- 流水按日期分组，显示当天消费合计，以及累计存入、累计消费、本月消费。
- 金额按「分」存成整数，不会有小数误差。
- 页面开着过了午夜，默认日期会自动换成新的一天。

### 共享版独有
- **按人记账**：先添加一起吃饭的成员。
  - 存入时选是谁存的。
  - 消费时勾选谁吃了，可以**平均分摊**（除不尽的几分钱依次分给前几个人，合计不差一分），也可以**各付各的**（每人填自己的金额，自动合计）。
  - 每人一张余额卡：存了多少、吃了多少、还剩多少，负数就是该补钱了。
  - 成员可以改名、停用（停用后不再出现在勾选里，历史记录保留）。
  - 流水可以按成员筛选，看某个人的分摊明细。
- **修改记录**：记错了点「编辑」直接改，之前的版本会保存下来，并标注「某某修改过」。
- **删除可追溯**：删除不会真的抹掉数据，勾选「显示已删除」能看到是谁删的，还可以恢复。
- **权限**：普通成员只能编辑、删除自己记的流水；管钱的人（页面所有者或 Editor）可以改所有记录。
- **操作记录**：最近 50 条新增、修改、删除、恢复、成员变动，谁在什么时候做的都看得到。
- 「今日已抽中」的结果和抽的人，大家都能看到。

> 权限和操作记录是为了让账目透明、方便追查，不是严格的安全机制：能记账的人在技术上仍可以绕过页面直接改数据。同事之间用足够了。

### 备份
- 单机版：「导出备份」下载 JSON 文件，「导入备份」恢复（会覆盖当前数据）。
- 共享版：「备份与导入」里可以复制全部数据（含成员和分摊），也可以导入单机版或共享版导出的 JSON（追加，不覆盖；成员按名字合并）。

## 本地运行

直接用浏览器打开 `index.html` 即可。或者起一个本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。

`shared/lunch.html` 只能在 claude.ai 里运行，直接打开会提示「需要在 claude.ai 中打开」。

## 部署

- **单机版**：仓库 Settings → Pages，Source 选 *Deploy from a branch*，分支选 `main`，目录 `/ (root)`。推送后自动更新。
- **共享版**：修改 `shared/lunch.html` 后，需要在 Claude 里重新发布到同一个 artifact 链接，云端数据不会受影响。

## 数据格式

单机版的备份 JSON：

```json
{
  "restaurants": [{ "name": "兰州拉面" }],
  "transactions": [
    { "type": "deposit", "amount": 50000, "date": "2026-11-17", "note": "小王存入", "created": 1794935802000 },
    { "type": "expense", "amount": 1850,  "date": "2026-11-17", "note": "兰州拉面", "created": 1794935900000 }
  ]
}
```

共享版在此基础上加了成员和分摊（`"version": 2`）：

```json
{
  "version": 2,
  "members": [{ "id": "m1", "name": "小王", "active": true }, { "id": "m2", "name": "小李", "active": true }],
  "restaurants": [{ "name": "兰州拉面" }],
  "transactions": [
    { "type": "deposit", "amount": 10000, "date": "2026-11-18", "note": "", "created": 1794935802000, "member": "m1" },
    { "type": "expense", "amount": 1001,  "date": "2026-11-18", "note": "兰州拉面", "created": 1794935900000,
      "shares": { "m1": 501, "m2": 500 }, "split": "equal" }
  ]
}
```

- `type`：`deposit` 存入，`expense` 消费
- `amount`：金额，单位是**分**（`1850` = $18.50）
- `date`：记账日期 `YYYY-MM-DD`
- `created`：创建时间（毫秒时间戳），用来给同一天的记录排序
- `member`：存入人的成员 id（共享版）
- `shares`：每位成员分摊的金额（分），合计等于 `amount`；`split` 为 `equal`（平均）或 `custom`（各付各的）

共享版云端还有两个集合：`log`（操作记录）和 `picks`（每天的抽奖结果）。每条流水另带 `by`（记录人）、`updatedAt`/`updatedBy`/`history`（修改历史）、`deleted`/`deletedBy`（软删除）字段。
